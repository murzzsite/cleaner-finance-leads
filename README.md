# Клинер Финанс — лендинг прямой лидогенерации

Лендинг под задачу клиента: запустить прямую лидогенерацию на конечного потребителя, отдельно от партнёрского канала (риелторы/застройщики/брокеры), который сейчас приносит все заявки.

## Заглушки, которые нужно заменить
- Телефон в шапке и футере: `+7 (900) 123-45-67` — реальный телефон не давали в брифе.
- В privacy.html нет ИНН/юр. названия — не указывали в брифе, добавить при уточнении.
- Реальный сайт клиента (Tilda, cleaner-finance.ru) использует партнёрскую реф-систему (cf_partner_id/cf_ref) — на этом лендинге её нет намеренно, так как задача — прямые лиды, не партнёрские.
